# Ritim v0.9.0-alpha.2 — Taslak

## Türkçe

Bu sürüm henüz yayınlanmamış Alpha.2 altyapı çalışmasıdır.

- Raspberry Pi için PostgreSQL, Redis ve sosyal gateway Docker Compose temeli
- Host'a açılmayan PostgreSQL/Redis ağı
- Loopback ile sınırlı sosyal gateway
- En az yetkili PostgreSQL uygulama rolü ve başlangıç şeması
- PostgreSQL bağlantı havuzu ile `/health` ve `/ready` kontrolleri
- OAuth ve token güvenlik kapıları için uygulama planı

## English

This is an unpublished draft of the Alpha.2 infrastructure work.

- PostgreSQL, Redis, and social gateway Docker Compose foundation for Raspberry Pi
- PostgreSQL and Redis isolated from host networking
- Loopback-only social gateway publishing
- Least-privilege PostgreSQL application role and initial schema
- PostgreSQL connection pooling with `/health` and `/ready` probes
- Implementation plan and security gates for OAuth and tokens
