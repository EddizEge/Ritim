# Ritim v0.9.0-alpha.2

## Türkçe

- Raspberry Pi için PostgreSQL, Redis ve sosyal gateway Docker Compose temeli
- Host'a açılmayan PostgreSQL/Redis ağı
- Loopback ile sınırlı sosyal gateway
- Cloudflare Tunnel üzerinden `https://social.edizegemercan.com.tr` HTTPS/WSS
  erişimi
- En az yetkili PostgreSQL uygulama rolü ve başlangıç şeması
- PostgreSQL bağlantı havuzu ile `/health` ve `/ready` kontrolleri
- PostgreSQL üzerinde kalıcı kullanıcı, cihaz, doğrudan konuşma, mesaj ve oda
  repository katmanı
- Redis TTL tabanlı cihaz presence ve beraber dinleme durumu
- Gateway yeniden başlatıldıktan sonra mesaj ve aktif odaları geri yükleyen
  entegrasyon testi
- Google Authorization Code + PKCE ve Android ID token giriş endpoint'leri
- Google JWKS/issuer/audience doğrulaması ve `issuer + sub` hesap kimliği
- 15 dakikalık access token, döndürülen hash'li refresh token, tekrar kullanım
  tespiti, logout ve cihaz iptali
- Auth-required Socket.IO bağlantısı ve istemci kimlik sahteciliğine karşı
  sunucu authoritative profil
- Electron PKCE istemcisi, Windows `safeStorage` token kasası ve sosyal socket
  access-token yenilemesi
- Android Keystore/AES-GCM sosyal token kasası
- Android Keystore tarafından üretilen GCM IV ile gerçek Samsung cihazında
  doğrulanmış güvenli oturum saklama
- Mevcut PC–telefon eşlemesi üzerinden 120 saniyelik tek kullanımlık companion
  ticket ve aynı hesapta bağımsız telefon session'ı
- Exact-origin CORS, güvenlik başlıkları, güvenilir proxy yapılandırması,
  HTTP/auth/socket bağlantı limitleri ve olay başına abuse koruması
- PostgreSQL üzerinde kalıcı tepkiler; çift yönlü engelleme ile profil,
  mesaj, oda ve birlikte dinleme filtreleri
- Profil ve dinleme için herkes/konuştuklarım/gizli görünürlük tercihleri
- 4 TB diske günlük, 2 TB diske haftalık AES-256 şifreli yedek ve gerçek
  geçici veritabanına otomatik geri yükleme provası
- Aynı hesaptaki PC ve telefon ile geçici ikinci hesap arasında gerçek
  görünürlük, mesaj ve tepki kabul testi

## English

- PostgreSQL, Redis, and social gateway Docker Compose foundation for Raspberry Pi
- PostgreSQL and Redis isolated from host networking
- Loopback-only social gateway publishing
- HTTPS/WSS access through Cloudflare Tunnel at
  `https://social.edizegemercan.com.tr`
- Least-privilege PostgreSQL application role and initial schema
- PostgreSQL connection pooling with `/health` and `/ready` probes
- Durable PostgreSQL repositories for users, devices, direct conversations,
  messages, and listening rooms
- Redis TTL-backed device presence and listening-together state
- Integration coverage that restores messages and active rooms after a gateway
  restart
- Google Authorization Code + PKCE and Android ID-token sign-in endpoints
- Google JWKS, issuer, and audience validation with `issuer + sub` identity
- 15-minute access tokens, rotating hashed refresh tokens, reuse detection,
  logout, and device revocation
- Auth-required Socket.IO connections with server-authoritative identity
- Electron PKCE client, Windows `safeStorage` token vault, and social socket
  access-token refresh
- Android Keystore/AES-GCM social token vault
- Secure session storage verified on a physical Samsung device with a
  Keystore-generated GCM IV
- 120-second single-use companion tickets over existing PC–phone pairing,
  creating an independent phone session under the same account
- Exact-origin CORS, security headers, trusted-proxy configuration,
  HTTP/auth/socket connection limits, and per-event abuse protection
- Durable PostgreSQL reactions plus bidirectional block enforcement across
  profiles, messages, rooms, and listening-together state
- Everyone/contacts/hidden visibility preferences for profile and listening
- Daily AES-256 encrypted backups to the 4 TB disk, weekly restore points to
  the 2 TB disk, and an automated real temporary-database restore smoke test
- End-to-end presence, message, and reaction acceptance testing between the
  same-account PC/phone pair and a temporary second account
